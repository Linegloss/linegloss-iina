# Linegloss for IINA

Explain the subtitle you paused on, clip its audio, and save both to your [Linegloss](https://linegloss.com) library. A plugin for the [IINA](https://iina.io) media player on macOS.

## Install

1. Install IINA 1.4 or newer.
2. In IINA, open **Settings → Plugins**, choose to install a plugin from GitHub, and enter `Linegloss/linegloss-iina`.
3. Allow the permissions IINA lists, and restart IINA if it asks.

Or download `linegloss-<version>.iinaplgz` from the [latest release](https://github.com/Linegloss/linegloss-iina/releases/latest) and open it with IINA. Either way, IINA offers updates when a new version is published.

## Connect Your Library

1. Sign in at [linegloss.com](https://linegloss.com), open **Settings → IINA plugin**, and create a plugin token. Choose how long it lasts; you can revoke it there at any time.
2. In IINA, open **Settings → Plugins → Linegloss**, paste the token into **Library**, and choose **Connect**.

## Use It

Pause on a line and press **⌘K**, or choose **Explain Subtitle…** from the plugin menu. Pick the lines to include, choose **Explain**, and save the result to your library, with the line's audio if you like. You can change the shortcut in the plugin's settings.

Explanations use the Linegloss hosted model (beta) by default, which needs only the plugin token and has a daily limit. To use your own OpenAI, DeepSeek, or OpenAI-compatible API key instead, choose **My own API key** in the plugin's settings. The key stays on your Mac.

## About This Repository

This repository holds the built plugin that IINA installs: `Info.json`, `dist/`, and `PROVENANCE.json`, which names the source commit. The files are generated by the Linegloss release process and overwritten on every release, so pull requests against them can't be merged. Please report problems and ideas in [Issues](https://github.com/Linegloss/linegloss-iina/issues).
